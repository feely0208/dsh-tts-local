# @deepwhale-cn/dsh-tts-local

macOS say 命令 + edge-tts，完全离线零 Key（深鲸守护系列 · 基于 dsh-guard-core）

## 用法

```bash
npx @deepwhale-cn/dsh-tts-local --root <项目目录>
npx @deepwhale-cn/dsh-tts-local --demo        # 内置样本演示
npx @deepwhale-cn/dsh-tts-local --list-rules  # 判据与法规出处
npx @deepwhale-cn/dsh-tts-local --html r.html # HTML 报告
```
